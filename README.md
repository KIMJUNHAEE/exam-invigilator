# 시험 종료 3분 전

학생 행동을 보고 부정행위자를 찾아내는 1인칭 3D 시험감독 게임. 부정행위자를 적발하면 학생이 놀라 양손을 들어 올린 뒤 폭발 효과와 함께 사라진다. 일반 학생을 지목하면 체력 3칸 중 1칸을 잃는다.

## 실행

- 온라인: https://kimjunhaee.github.io/exam-invigilator/ 에 PC의 Chrome 또는 Edge로 접속한다.
- `index.html`을 Chrome 또는 Edge로 연다. 파일 하나에 WebAssembly와 화면 코드가 들어 있어 인터넷 연결과 개발 서버 없이 실행할 수 있다.
- 첫 화면에서 **1단계 시작**, **2단계 시작**, **3단계 시작** 중 하나를 누르면 그 단계가 바로 시작되고 시점 조작이 활성화된다. 마우스 잠금이 풀린 상태에서는 게임 화면 안에서 마우스를 움직여 시점을 돌릴 수 있다. 이동키를 누르거나 게임 화면을 클릭하면 마우스 잠금이 다시 적용된다.

| 조작 | 동작 |
| --- | --- |
| WASD / 마우스 | 순찰 이동 / 시점 회전 |
| Shift | 이동 중 달리기 (스태미나 소모) |
| 마우스 우클릭 | 확대경 켜기/끄기 |
| F | 조준한 학생 즉시 적발 |
| T | 게임 방법과 설정 열기/닫기, 다음 단계로 이동 |
| Esc | 메뉴 닫기 또는 일시정지 |

책상이나 학생을 조준하면 책상에 표시가 생기고, 가까운 자리에서는 F 안내가 나타난다. T 메뉴에서는 마우스 감도와 각 효과음 음량을 조절할 수 있다. 메뉴가 열려 있는 동안 시험 시간은 멈춘다.

| 단계 | 교실 | 부정행위자 | 제한 시간 |
| --- | --- | --- | --- |
| 1단계 | 4열 × 5행, 학생 20명 | 4명 (미세 카메라 1, AI 답안 1, 쪽지 교환 1쌍) | 3분 |
| 2단계 | 8열 × 5행, 학생 40명 | 8명 (미세 카메라 2, AI 답안 2, 쪽지 교환 2쌍) | 5분 |
| 3단계 | 대강의실, 10석 × 6줄, 학생 60명 | 12명 (미세 카메라 3, AI 답안 3, 쪽지 교환 3쌍) | 8분 |

3단계 대강의실은 3-4-3 구역으로 나뉜 긴 책상 줄이 교탁 쪽을 향해 살짝 휘어 있고, 뒤로 갈수록 한 줄에 한 단씩 높아진다. 통로에는 계단이 있지만 점프 없이 걸어서 오르내릴 수 있다.

부정행위자를 모두 적발하면 결과 화면의 다음 단계 시작 버튼으로 이어서 진행한다. 실패하면 같은 단계를 다시 시작하고, 3단계까지 클리어하면 1단계부터 다시 시작한다. 시험 중 T 메뉴의 **다음 단계로 이동** 버튼을 누르면 바로 다음 단계로 넘어간다. 체력과 스태미나는 단계마다 가득 채워진다.

Shift를 누르고 이동하면 1.7배 속도로 달린다. 스태미나는 약 4초 달리면 바닥나고, 멈추고 0.7초 뒤부터 회복된다. 바닥난 뒤에는 35%까지 회복될 때까지 달릴 수 없다.

남은 시간은 교실 뒤 벽 시계에 표시된다. 제한 시간이 지나거나 체력이 0이 되거나 부정행위자를 모두 적발하면 결과 화면에서 실제 부정행위자 좌석과 행동이 공개된다. 부정행위자 자리와 행동 시각은 판마다 무작위로 정해진다.

오인 적발을 당한 학생은 감독관을 쳐다보고 가운데 손가락을 올린다. 마지막 체력이 차감되면 그 반응을 약 1.5초 보여준 뒤 결과 화면으로 넘어간다.

학생은 각자 다른 헤어스타일과 옷차림으로 구분된다. 21번 이후 학생은 기존 20명의 머리, 옷, 색을 겹치지 않게 다시 조합한다. 평소에는 시험지를 적다가 칠판이나 천장을 잠시 바라본다. 부정행위가 시작되면 안경이나 단추의 빨간불과 반복되는 귀 터치, 책상 아래를 보는 행동, 앞뒤 자리 사이의 쪽지 교환을 관찰할 수 있다. 쪽지를 던진 학생과 받은 학생은 각각 적발할 수 있다.

## 다시 빌드

Windows PowerShell에서 프로젝트 폴더를 열고 실행한다.

```powershell
.\build.ps1
```

C++23과 WebAssembly 타깃을 지원하는 Clang 및 wasm-ld가 필요하다. 스크립트는 PATH의 Clang을 찾으며, 없으면 Unity Hub Editor의 WebGL 모듈에 포함된 Clang을 찾는다. 경로를 직접 지정할 때는 `-Clang` 옵션을 사용한다.

- `src/game.cpp`는 시간, 시나리오, 이동·충돌, 시선 판정, 체력과 적발 판정을 맡는다. C++23으로 컴파일해 브라우저에서 WebAssembly로 실행한다.
- `web/students.js`는 학생 20명의 외형, 관절 애니메이션과 쪽지 궤적을 맡는다. `web/renderer.js`는 교실과 학생을 WebGL 2로 그린다.
- `web/audio.js`는 연필, 종이, 쪽지 착지와 발소리를 합성한다. 교실 안 소리는 해당 좌석 위치에 맞춰 들린다.
- `web/game.js`, `web/index.template.html`, `web/ui.css`는 브라우저 입력, HUD와 메뉴를 맡는다.

## 배포

GitHub 저장소 `KIMJUNHAEE/exam-invigilator`의 GitHub Pages로 배포한다. `.gitignore`가 `index.html`, `README.md`, `.nojekyll`, `.gitignore`만 올라가게 막고 있어서 소스 코드와 기획 문서는 저장소에 올라가지 않는다. 수정한 뒤 `.\build.ps1`로 다시 빌드하고 `index.html`을 커밋해 push하면 1~2분 안에 위 주소에 반영된다.
